`vina` is the Autodock Vina binary file for AutoDock Vina 1.1.2. The binary file is compiled for x86 Linux. The source code is available at https://vina.scripps.edu/downloads/. The binary file is compiled by the author of AutoDock Vina.

`Vina-GPU` is the compiled binary file for Vina-GPU. The source code is available at https://github.com/DeltaGroupNJUPT/Vina-GPU (5000561). The code is compiled on Lawrencium ES1 cluster (a40)

`Kernel2_Opt.bin` is the kernel file for Vina-GPU compiled on Lawrencium ES1 cluster (a40). Recompilation is required for a different system. Follow the instructions in Vina-GPU repository.
